# LinQ — система видеоконтроля промбезопасности

Монорепозиторий: `frontend/` (React + Vite), `backend/` (FastAPI), `db/` (схема PostgreSQL) + `docker-compose.yml`.
Собран из веток `feature/ui-dashboard` (интерфейс), `db` (схема и docker), `backend` (API).

## Запуск
1. БД: `docker compose up -d` (PostgreSQL, схема из `db/schema.sql` применяется сама; строка подключения — `DATABASE_URL` в `.env`).
2. Бэкенд: `cd backend && pip install -r requirements.txt && uvicorn main:app --reload` (порт 8000, Swagger: `/docs`).
   При первом запуске создаются демо-пользователи и 3 камеры. Логины: `mikhalyich_ot` (роль 1), `disp_smena1` (3), `master_ceh1` (2), `it_linq_admin` (7); пароль `linq123` (env `SEED_PASSWORD`).
3. Фронтенд: `cd frontend && npm install && npm run dev` → http://127.0.0.1:5173 (запросы `/api/*` проксируются на бэкенд; для другого адреса — `VITE_API_URL`).

## Как связано
- Интерфейс показывает экран входа, затем загружает камеры, события, настройки и статистику с API.
- Правила, зоны, PTZ и позиции камер сохраняются автоматически (через 0.6 с), при отказе по правам — откат. Журнал инцидентов опрашивает `/events?since_id=` каждые 5 с. Реакция на событие (подтвердить / мастеру / ложная) и комментарий пишутся в БД. «Тестовый инцидент» создаёт событие через `POST /events`.
- AI-сервис присылает нарушения на `POST /events` с заголовком `X-Api-Key` (env `INGEST_KEY`, по умолчанию `dev-ingest-key`).
- Права: просмотр — роли 1,2,3,7; правка камер/зон/правил/настроек/пользователей — 1 и 7; реакция на события — 1,2,3; PTZ — любой.
